Task Doc：右侧信息面板重排与协调性优化（方案 C）
1. 目标
将右侧信息面板从上到下调整为：
Year Summary
Personal Best
Total Summary
并通过轻量样式优化，解决“右侧不协调、视觉过重”的问题。
（不做大改布局，不引入新组件体系，保证一次改完可上线）
2. 现状依据（代码基线）
Dashboard 页有 selectedYear 与 data.stats（可作为 Year Summary 数据源）。.
右侧统计组件 GlobalPanel 当前顺序是“全历史统计 -> 个人最佳”。.
右侧样式当前视觉重量较高（深背景 + 高饱和值 + 卡片 hover）。.
3. 改动范围（文件清单）
frontend/src/features/activity-dashboard/components/GlobalPanel/GlobalPanel.tsx
frontend/src/features/activity-dashboard/components/GlobalPanel/GlobalPanel.module.css
frontend/src/features/activity-dashboard/components/DashboardLayout/DashboardLayout.tsx
（如有类型约束）frontend/src/features/activity-dashboard/components/GlobalPanel/GlobalPanel.type.ts
4. 实施任务拆分（按顺序执行）
Task A：接入 Year Summary 数据（P0）
在 DashboardLayout 中把 data?.stats 传给 GlobalPanel（新增 prop：yearStats、yearLabel）。
若 data 为空，Year Summary 显示 skeleton/占位值。
同时保持 globalStats 作为 Total Summary 与 Personal Best 数据源。
完成标准
GlobalPanel 可同时拿到：yearStats + globalStats.personalBest + globalStats.totalStats。
Task B：重排 GlobalPanel 内容顺序（P0）
在 GlobalPanel.tsx 内按以下顺序渲染 section：
Year Summary（顶部，主信息）
Personal Best（中部）
Total Summary（底部，次级）
完成标准
视觉顺序和信息层级符合你指定方案。
文案统一（可英文或双语，但全局一致）。
Task C：样式减重（P0）
在 GlobalPanel.module.css 做最小可见优化：
.container：背景透明度略降、边框更轻、阴影不过强。
.section：gap 从 1rem 调到 1.2~1.25rem。
主值字号分级：Year > Personal Best >= Total。
色彩分级：Year 用主色，Total 用中性色，减少“同级抢眼”。
完成标准
右侧仍有层次，但不压过左侧列表。
同屏观看时，左表与右面板视觉平衡。
Task D：页面挂载检查（P1）
确保 DashboardLayout 中 GlobalPanel 在你当前页面结构里正常显示（当前有注释块，需按你的页面版本确认是否启用）。.
完成标准
右侧 panel 在 list tab 可稳定显示；切换年份能同步更新 Year Summary。
5. 验收清单（QA Checklist）
 右侧顺序：Year Summary → Personal Best → Total Summary。
 Year Summary 数值随年份切换变化。
 Personal Best 与 Total Summary 仍显示正确。
 视觉层级更清晰，右侧不再“厚重突兀”。
 无 TS 报错、无明显样式回归。
 移动端/窄屏未破版（至少 768px 断点验证）。
6. 建议测试命令（改完后一次跑）
cd frontend && pnpm type-check
cd frontend && pnpm lint
cd frontend && pnpm test（如时间紧可先跳过全量测试）
7. 风险与回滚
风险
Year Summary 数据来源未正确透传，导致空值显示。
改色过度导致可读性下降。
断点布局被影响（尤其面板宽度）。
回滚方案
保留旧 section 渲染块注释（或单独 commit）。
样式改动集中在 GlobalPanel.module.css，可快速回退单文件。

# 社交媒体二维码图片

这个目录用于存放社交媒体账号的二维码图片。

## 需要添加的图片

请添加以下两个二维码图片：

### 1. 微信二维码
- **文件名**: `wechat-qr.png`
- **用途**: 在"关于我"页面展示微信二维码
- **获取方式**: 
  1. 打开微信
  2. 进入"我" → 点击头像 → "我的二维码"
  3. 保存二维码图片

### 2. 小红书二维码
- **文件名**: `xiaohongshu-qr.png`
- **用途**: 在"关于我"页面展示小红书二维码
- **获取方式**:
  1. 打开小红书 APP
  2. 进入个人主页
  3. 点击右上角"分享" → "二维码"
  4. 保存二维码图片

## 图片要求

### 格式
- **推荐格式**: PNG（支持透明背景）
- **支持格式**: PNG, JPG, JPEG, WEBP

### 尺寸
- **推荐尺寸**: 250x250 像素或更大（正方形）
- **最小尺寸**: 200x200 像素
- **宽高比**: 1:1（正方形）

### 文件大小
- **建议**: 小于 500KB
- **最大**: 2MB

## 使用说明

1. 将二维码图片保存到此目录
2. 确保文件名正确：
   - 微信：`wechat-qr.png`
   - 小红书：`xiaohongshu-qr.png`
3. 刷新页面即可看到效果

## 注意事项

- 二维码图片应该是清晰的，确保可以正常扫描
- 建议使用高质量的二维码图片，避免模糊
- 如果二维码有背景色，建议使用白色背景
- 图片会自动居中显示，无需担心对齐问题

## 示例

```
public/
└── images/
    ├── wechat-qr.png        # 微信二维码
    ├── xiaohongshu-qr.png   # 小红书二维码
    └── README.md            # 本说明文件
```

## 隐私提示

- 二维码图片会被公开访问，请确保你愿意分享这些社交账号
- 如果不想公开某个社交账号，可以不添加对应的二维码图片
- 可以随时删除或替换这些图片
